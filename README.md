
# 📊 Power BI Dashboard – OTT Platforms (Netflix, Prime Video, JioHotstar)

## 📌 Project Overview

This repository contains an interactive **Power BI dashboard** analyzing content across multiple **OTT platforms** – **Netflix, Amazon Prime Video, and JioHotstar**.

The dashboard provides actionable insights into movies and TV shows, helping users understand content distribution, trends, and audience preferences across platforms.

## 🚀 Features

* ✅ Interactive dashboard for comparing **Movies & TV Shows** across multiple OTT platforms
* ✅ Visualizations of **content distribution** by platform, release year, genre, duration, and ratings
* ✅ Custom **DAX measures** for advanced calculations (e.g., Short/Medium/Long movies classification)
* ✅ Country-level insights on where content is produced and available
* ✅ Clean, professional layout with filters and slicers for easy exploration

## 🛠️ Tools & Technologies

* **Power BI Desktop** – Dashboard development
* **Power Query** – Data cleaning & transformation
* **DAX (Data Analysis Expressions)** – Custom calculations
* **CSV datasets** – OTT content information
